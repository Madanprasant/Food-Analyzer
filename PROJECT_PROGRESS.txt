PLATESIGNAL — PROJECT PROGRESS
Updated: 2026-08-30

COMPLETED AND VERIFIED

1. Foundation and interface
   - Separate React/Vite frontend and FastAPI backend.
   - Responsive black, charcoal, and gold visual system.
   - Desktop layout expanded to use the full screen width.
   - Mobile-friendly layouts, touch-sized controls, camera-capable image input, and reduced-motion support.
   - Local Wi-Fi preview is supported with no website hosting required.

2. Model integration
   - Integrated the supplied EfficientNetV2-S checkpoint.
   - Validated checkpoint head: 239 output classes.
   - Validated supplied class list: 239 classes.
   - Model loads once when backend starts.
   - Replaceable FoodClassifier contract is in place.
   - Actual model inference, actual probability confidence, and actual Top-5 predictions work.

3. MongoDB, accounts, and security
   - MongoDB Atlas connection is working.
   - Email/password signup, login, JWT sessions, logout, password hashing, and protected user routes are implemented.
   - Profile/onboarding data persists in MongoDB.
   - User data is scoped to the signed-in user.
   - Firebase Google Sign-In frontend and backend token-verification path are integrated; Firebase configuration is required for use.

4. Onboarding improvements
   - Clear activity, goal, and dietary-preference choices.
   - Default “suggest my starting targets” calculation for calories and protein using profile, activity, and goal.
   - Optional manual targets for people who already have an external plan.
   - Explicit “No known allergies” and “No foods to avoid” choices.
   - Common allergy and food-to-avoid options, plus preferred-food input.

5. Food-analysis and nutrition flow
   - Authenticated image upload (JPEG, PNG, WebP; 5 MB maximum).
   - Image validation and safe local development storage.
   - Live image preview and mobile camera input.
   - Real prediction, confidence indicator, Top-5 selection, low-confidence warning, and search across all 239 classes.
   - Serving selector: small, regular, or large.
   - Final-food confirmation and correction tracking.
   - User-isolated meal history and dashboard history preview.
   - Imported 239 traceable nutrition seed records into MongoDB.
   - 36 direct IFCT records have verified per-100g values; source energy is retained in kJ and displayed kcal is converted deterministically.
   - 87 recipe/composite foods and 116 secondary-source foods remain nutrition-pending; no values are invented.
   - Direct IFCT foods require the user to enter grams; servings, snapshots, daily totals, weekly totals, and the rule-based Meal Balance Score are calculated deterministically.
   - The complete upload → prediction → confirmation → save flow was tested successfully with MongoDB and the model.
